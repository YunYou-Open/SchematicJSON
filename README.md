# Minecraft Schematic to JSON Converter

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

将 Minecraft `.schematic` 文件转换为 JSON 格式的工具

## 功能说明

- 支持大多数 Minecraft 方块ID映射
- 保留方块位置、类型和元数据
- 特殊方块处理
- 交互式命令行界面

## 声明须知

- 使用本工具造成任何后果与 YunYou 无关
  
## 安装使用

```bash
git clone https://github.com/YunYou-Open/SchematicJSON.git
cd SchematicJSON
go run main.go
